# Orbit V0.0.4 M27 — Dependency-driven invalidation

Status: **Implementation in progress**

M27 wires V0.0.4 terrain outputs into the existing V0.0.3 `ProceduralGraph` instead of introducing a second scheduler.

## Per-page graph

Every registered physical page owns page-local source nodes and the following derived chain:

    rock physics + authoring
              ↓
           geology
              ↓
    climate + authoring
              ↓
           drainage
              ↓
    climate + water + process settings
              ↓
        terrain processes
              ↓
        exposed surface
              ↓
    climate + biome placement
              ↓
         biome weights
          ↙       ↘
 biome surface   biome scatter
      ↓               ↓
surface material    scatter

## Split biome dependencies

Biome edits are deliberately split into three source branches:

- placement/rules;
- surface material;
- scatter.

Therefore a forest tree-density edit invalidates only scatter, while a moss material edit invalidates only surface material. Neither source is an ancestor of erosion.

## Geological/process propagation

Rock-physics edits invalidate geology and every dependent drainage/process/surface/biome/scatter descendant. Climate, water and process-setting sources enter only the stages that consume them.

## Spatial invalidation

Local requests use the canonical cube-aware `TileNeighborhood` at the physical page tile level. The request contains a direct radius plus an explicit bounded downstream radius for effects such as canyon edits changing neighboring drainage.

Only registered pages intersecting that bounded neighborhood have their source nodes invalidated. Distant pages retain clean committed graph products.

## Revisions and M26 cache

Each affected page advances only the corresponding `TerrainGenerationRevisions` domain. The same page address is invalidated from the M26 persistent GPU cache so old revision resources are released; unaffected page addresses remain resident.

## Acceptance coverage

`Orbit.TerrainDependency` verifies:

- forest tree-density changes rebuild scatter without rerunning terrain processes;
- moss material changes rebuild surface material without erosion or scatter;
- bedrock/rock-physics changes rebuild geology and erosion descendants;
- local authoring with one-tile downstream reach leaves distant page products clean;
- biome scatter edits advance only the biome revision domain;
- affected M26 cache entries are invalidated with the graph edit.

The milestone remains in-progress until branch-head warnings-as-errors compilation and the isolated terrain regression lane pass.
