# Orbit V0.0.4 — M06 Base Relief and Derivative Procedural Fields

Status: **implemented and verified**

Branch: `orbit`

Completed: 2026-09-18

M06 establishes the process-independent procedural relief layer downstream of M05. It produces continental base relief, ridge/valley detail, analytic tangent derivatives and physical-footprint spectral filtering without turning M05 uplift into final mountain height.

## 1. Authority / derivation boundary

```text
M05 macro uplift + drainage guidance
             │
             ├──────────────→ forwarded forcing for M09/M10
             │
M06 procedural relief recipe
  ├─ continental base band
  ├─ ridge bands
  └─ valley bands
             ↓
analytic body-space evaluation
             ↓
height + dh/deast + dh/dnorth
             ↓
derived terrain pages / later processes
```

M06 is derived procedural state. Individual cheap noise octaves are evaluated directly and are not cached as authority.

## 2. Canonical body-space sampling

Every band evaluates from the M01 canonical unit direction:

```text
noisePosition = unitDirection * (planetRadius / wavelength)
```

No cube-face UV, clipmap ring, cache slot or camera coordinate participates in phase.

Changing the physical footprint changes only a band's spectral weight. It does not change its coordinate, seed or phase.

## 3. Relief components

`BaseReliefField` produces:

- signed continental base relief and bias;
- positive ridged detail;
- negative valley detail;
- combined procedural height;
- normalized ridge/valley/geological-detail signals;
- analytic tangent derivative;
- forwarded M05 uplift/drainage/protection values.

The M05 uplift channel is deliberately not added directly to `heightMeters`. M09/M10 remain responsible for turning uplift + resistance + drainage into large-scale equilibrium landform.

## 4. Analytic derivatives

M06 analytically differentiates the same quintic value-noise interpolation used for height.

For each lattice interpolation axis:

```text
v = lerp(a, b, w)
dv = lerp(da, db, w) + (b-a) dw
```

The 3D noise derivative is converted to physical east/north slope using the sphere chain rule.

Because:

```text
noisePosition = direction * radius / wavelength
d(direction)/d(surfaceMeters) = tangent / radius
```

then:

```text
d(noisePosition)/d(surfaceMeters) = tangent / wavelength
```

so M06 returns local slopes:

```cpp
dh / d(meters east)
dh / d(meters north)
```

These derivatives can later drive normals, curvature and derivative-based detail without separately finite-differencing clipmap samples.

## 5. Physical-footprint frequency cutoff

All M06 bands use one physical rule:

```text
wavelength <= 2 × footprint  → 0
wavelength >= 4 × footprint  → 1
between                         smooth quintic crossfade
```

This uses `TerrainSampleFootprint`, not a render LOD integer.

Sub-resolution frequencies therefore disappear progressively rather than aliasing into coarse pages.

## 6. No per-octave cache

M06 evaluates cheap procedural bands directly.

The cache boundary remains:

```text
cheap analytic octaves        → evaluate
expensive/final derived page  → cache downstream
```

This avoids cache bandwidth/metadata overhead for values cheaper to regenerate than fetch.

## 7. Process-independent geological fields

The M06 sample exposes:

```cpp
ridgeSignal
valleySignal
geologicalDetailSignal
```

These describe procedural shape only. They do not own sediment, erosion, biome or renderer-material authority.

## 8. Acceptance coverage

`Orbit.TerrainRelief` verifies:

- analytic east/north height derivatives against centered finite differences;
- removing an unresolvable octave leaves retained-band height and derivative phase unchanged;
- spectral weights fade monotonically through a real transition range;
- the same physical position addressed through adjacent cube faces evaluates to the same height;
- M05 macro uplift is forwarded exactly but is not baked into M06 procedural height.

## 9. M06 invariants

1. **Procedural phase is canonical body-space, never face/clipmap local.**
2. **LOD changes spectral amplitude only; they cannot re-seed or rephase a band.**
3. **Unrepresentable frequencies are filtered before evaluation.**
4. **Height and derivative come from the same analytic function.**
5. **Cheap individual octaves are not cached.**
6. **M05 uplift remains forcing for later stream-power equilibrium, not direct M06 mountain height.**
