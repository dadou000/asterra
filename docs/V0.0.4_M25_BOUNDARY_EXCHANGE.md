# Orbit V0.0.4 M25 — Physical page boundaries and halo exchange

Status: **Complete**

M25 introduces one deterministic physical-neighbor exchange layer over the page-local boundary state already produced by M09, M14 and M17.

## Unified conservative transport

`SurfaceBoundaryFlux` carries:

- conservative water volume plus volume-weighted local tangent velocity;
- the canonical M14 `SedimentBoundaryFlux`.

M14's three media are reused directly:

- waterborne = hydraulic/coastal sediment;
- airborne = saltation/aeolian transport;
- surface-mobile = reptation, bedload and other surface transport.

No second sediment authority is created.

## Cube-face-safe remapping

`BuildDeterministicBoundaryTransfers` uses the existing canonical `PlanetTileNeighborhood` mapping for every physical edge:

- target tile;
- target edge;
- sample-order reversal;
- local tangent vector rotation.

Diagonal/corner packets use physical tile offsets and canonical corner directions, so edge/corner exchange does not depend on a hard-coded cube-face table.

## Deterministic synchronization

Input pages are sorted by stable physical address before transfer generation. Result edges/corners are sorted by receiving page, receiving edge/corner and source page.

Therefore:

- caller iteration order cannot change exchange order;
- camera/cache residency is absent from exchange identity;
- physical neighbor mapping remains stable across stream-out/stream-in.

## M14 integration

`ApplySedimentBoundaryTransfers` imports matching remapped packets directly into `SedimentExchangePage`, preserving M14 accounting. Airborne and surface-mobile packets can therefore migrate between physical pages instead of being pinned to the source edge.

## Water integration boundary

`IncomingWaterBoundaryFlux` returns the exact conservative water packet entering a receiving page. Hydraulic/coastal solvers remain the owners of their water state; M25 does not create a duplicate water simulation.

## Ghost/halo state

`BuildSurfaceBoundarySnapshot` captures a one-cell physical boundary from:

- M08 material columns;
- optional M09 drainage state;
- optional M17 shallow-water state.

`BuildDeterministicGhostTransfers` remaps those cells into neighbor-local orientation. Drainage D8 directions and coastal tangent velocities are rotated with the page mapping.

Adapters produce:

- a complete `DrainagePageHalo` for M09;
- a complete neighbor `CoastalBoundaryState` for M17.

## Acceptance coverage added

`Orbit.TerrainBoundaryExchange` verifies:

- two-page airborne/surface-mobile sediment migration;
- two-page mobile-sediment mass conservation;
- exact water-volume conservation through remapping;
- cross-cube-face sample ordering;
- cross-face tangent-vector remapping;
- deterministic ghost-transfer order independent of caller order;
- physical M08 ghost-edge equality.

The milestone remains in-progress until branch-head isolated terrain CI passes.
