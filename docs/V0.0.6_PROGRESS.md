## Frozen implementation principles

- Existing FrameGraph remains the spatial authority.
- Existing semantic World/System/Body hierarchy remains authority.
- Specialized behavior attaches through capabilities, not body subclasses.
- Presets create ordinary capabilities; they are never hidden runtime types.
- Physical properties use explicit units and solver provenance.
- Simulation LOD and rendering LOD remain independent.
- Ground terrain remains the accepted V0.0.5 production toroidal clipmap path.
- Orbital globes/impostors/point proxies are derived representations of the same body.
- All UI mutation uses shared commands/transactions.
- Exact properties remain accessible through the shared Inspector.
- No separate celestial editor or launcher is permitted.
- Complex physical/render models require a research note and deterministic validation before milestone acceptance.
- No fixed authoring caps are introduced for UI convenience.
- Derived GPU products are disposable and revisioned.
