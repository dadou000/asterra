# Orbit V0.0.4 — M05 Macro Geology and Uplift Field

Status: **implemented; verification pending**

Branch: `orbit`

M05 establishes the body-wide macro geological forcing that later drainage and stream-power milestones consume. It does not encode final mountain height as authority.

## 1. Authority chain

```text
tectonic state / hotspots
        +
M04 authored uplift/height/gradient/drainage/protection
        +
deterministic body-space geological distortion
        ↓
M05 MacroGeologyField
        ↓
uplift forcing + guidance fields
        ↓
M09 drainage routing
        ↓
M10 stream-power equilibrium
        ↓
derived large-scale landform
```

M05 therefore preserves the scaffold rule that uplift is authoritative input while the final mountain/valley surface remains derived.

## 2. Baseline tectonic uplift

M05 reuses the existing deterministic Orbit tectonic state exposed by `GlobalTerrainFields`:

- convergence mask;
- divergence mask;
- nearest/secondary plate continental identity;
- hotspot elevation.

Convergent boundaries create positive uplift forcing. Divergent boundaries contribute subsidence/rift forcing. Continental/continental, mixed and oceanic/oceanic collisions have separate authored scales.

Hotspot uplift is forwarded from the same deterministic tectonic field used by the existing global terrain system so 2D/global and 3D terrain representations do not invent separate plate systems.

## 3. Authored mountain belts and basins

M05 does not introduce new authority types.

`MakeMountainBeltConstraint()` creates an ordinary M04 spline uplift constraint with positive uplift.

`MakeBasinConstraint()` creates an ordinary M04 uplift constraint with negative uplift/subsidence.

Therefore the editor, serializer and later procedural graph continue to manipulate one terrain-authoring model:

```text
M04 TerrainConstraintSet
  uplift
    ├─ brush-painted uplift
    ├─ spline mountain belt
    ├─ basin/subsidence region
    └─ imported raster uplift
```

## 4. Imported source fields

The optional imported-source requirement is satisfied through M04 `RasterMaskConstraintPrimitive` used in the uplift field. Importers convert an external raster once into canonical tangent-space authority. M05 then evaluates it exactly like any other uplift constraint.

M05 does not add a renderer texture or another raster ownership path.

## 5. Geological distortion

`MacroGeologyField` adds long-wavelength deterministic body-space distortion.

The signal is:

- seeded from `PlanetDefinition::generationSeed` unless explicitly overridden;
- evaluated from canonical unit direction;
- continuous across cube faces and tiles;
- independent of camera and cache state;
- independent of render/clipmap LOD;
- limited to macro wavelengths.

It modulates tectonic uplift forcing rather than becoming a final-detail height function.

## 6. Drainage and stream-power boundary

Actual flow/depression routing belongs to M09 and stream-power equilibrium belongs to M10. M05 deliberately does not duplicate those solvers early.

M05 forwards M04 drainage guidance independently from uplift. This means repainting a mountain belt changes uplift forcing without silently overwriting authored river/drainage intent.

The later chain is:

```text
M05 uplift
+ M02/M03 geological resistance
+ M04 drainage guidance
        ↓
M09 routed drainage
        ↓
M10 stream-power equilibrium
```

This is the implementation form of the researched Schott et al. uplift-domain workflow.

## 7. Revision boundary

`MacroGeologyRevisionInputs` contains only:

```cpp
u64 geology;
u64 authoring;
```

Its fingerprint intentionally excludes:

- M06 fine-detail revision;
- biome revision;
- water revision;
- camera/view state;
- cache residency.

Changing small-scale detail therefore cannot invalidate the body-wide M05 uplift field.

## 8. Output contract

One query returns:

```cpp
struct MacroGeologySample
{
    double tectonicUpliftMeters;
    double tectonicSubsidenceMeters;
    double hotspotUpliftMeters;
    double distortionSignal;

    double upliftMeters;

    double authoredHeightMeters;
    Double2 gradientGuidance;
    double drainageGuidance;
    double protection;
};
```

`upliftMeters` is a forcing field for later equilibrium, not final terrain elevation.

## 9. Acceptance coverage

`Orbit.TerrainMacroGeology` verifies:

- increasing authored uplift changes macro mountain forcing;
- the same uplift edit preserves independent drainage guidance;
- mountain belts are ordinary M04 spline uplift constraints;
- basins are ordinary negative M04 uplift constraints;
- an imported raster mask can drive uplift;
- deterministic body-space distortion reproduces exactly for the same planet/seed/position;
- M05 revision identity depends only on geology + authoring;
- geology or authoring revision changes invalidate M05;
- cross-planet constraint authority is rejected.

## 10. M05 invariants

1. **Uplift is input authority; final mountain height is derived.**
2. **M05 consumes M04 authoring instead of introducing a second terrain-authoring format.**
3. **Plate convergence/divergence/hotspot state is shared with Orbit's existing deterministic global tectonic field.**
4. **Geological distortion is canonical body-space macro forcing, not tile-local detail noise.**
5. **Drainage authority survives uplift edits and is solved physically in M09/M10.**
6. **Fine-detail changes do not invalidate body-wide uplift.**

## 11. Next boundary

M06 — Base Relief and Derivative Procedural Fields can add continental relief and ridge/valley detail with analytic derivatives and LOD-frequency cutoff. M06 detail must remain downstream of M05 and must not become an input to M05 revision identity.
