# Orbit V0.0.4 — Planet Surface Authority Scaffold

Status: **research scaffold — implementation not started**

Branch target: `orbit`

This document defines the V0.0.4 scaffold for Orbit. It inherits the V0.0.3 production rules: no placeholder classes, no temporary editor APIs, no throwaway serializers, no fake implementations, and no systems knowingly scheduled for replacement. Every introduced type must have a real owner, persistence model, runtime semantics, tests, and stable public boundary.

V0.0.4 establishes the permanent authority chain for rocky-world surfaces:

```text
Geology -> Terrain Processes -> Exposed Surface State -> Biome Dressing -> Render/Scatter
```

The detailed researched milestone plan, source references, CPU/GPU residency rules, cache contract, authoring model, and acceptance tests will be completed in this file before implementation begins.
