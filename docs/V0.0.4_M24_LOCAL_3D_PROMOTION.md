# Orbit V0.0.4 M24 — Optional local 3D promotion

Status: **Complete**

M24 promotes only exceptional local terrain from the normal M08 heightfield/material-column representation into a bounded multi-layer vertical representation.

## Representation

A promoted cell stores ordered solid vertical spans. Gaps between spans are real voids, so one horizontal cell can represent:

- cave space below an intact roof;
- an undercut cliff;
- a disconnected arch/bridge of rock;
- a cave mouth whose vertical ray intersects solid more than once.

This is deliberately not a planet-wide voxel volume. Every promoted region has a finite vertical window around the existing M08 surface.

## Sparse authority boundary

`MaterialColumnPage` remains unchanged for ordinary terrain. A `Local3DPromotionRegion` exists only when `TryPromoteLocal3D` accepts an explicit or strict process-triggered request. Rejected/normal terrain receives a null result and owns no promotion buffers.

The promoted region is a local structural representation derived from the current physical M08 page. It does not convert render residency into terrain authority.

## Promotion rules

Explicit authoring may request promotion directly.

Process-triggered promotion requires all configured evidence thresholds:

- minimum void height;
- minimum undercut distance;
- minimum spatial persistence;
- minimum process confidence.

Process promotion can be globally disabled in the policy.

## Stable boundary

A configurable guard ring is initialized from the exact M08 surface and cannot be carved or extended by local 3D operations. `BoundaryMatches` verifies that this ring still has one span and the same top elevation as the normal material-column page.

This gives the promoted patch a deterministic handoff to ordinary terrain without forcing adjacent pages into 3D.

## Stable identity

`Local3DPromotionFingerprint` depends on the physical page address, source/promotion revisions, promotion reason/evidence and promotion policy. Camera, clipmap, frame and GPU residency state are absent.

## Initial operations

The production CPU representation supports:

- `CarveVoid`: subtracts a vertical interval and can split one solid span into two;
- `AddSolid`: adds disconnected/adjacent rock while rejecting conflicting material overlap;
- solid containment/top-surface queries;
- bounded maximum span count per cell;
- approximate owned-memory reporting.

## Acceptance coverage added

`Orbit.TerrainLocal3DPromotion` verifies:

- weak ordinary terrain does not allocate a 3D region;
- explicit promotion builds a one-span baseline matching M08;
- process promotion obeys strict evidence;
- cave carving creates a void with an intact overhang roof;
- boundary cells cannot be modified;
- disconnected rock can represent arch geometry;
- promotion identity is stable and explicitly revisioned.
